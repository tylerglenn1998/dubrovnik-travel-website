# Dubrovnik Travel Website

## About the Project
This is a travel website about Dubrovnik, Croatia that I created as a final project for a previous Web Development course. I uploaded this project to GitHub as part of my Fall CIS 260 coursework and to begin building my GitHub portfolio.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Multiple webpage navigation
- Responsive web design
- Images and video
- Information about Dubrovnik's history, culture, and travel attractions
